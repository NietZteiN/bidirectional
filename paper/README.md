# Papers

The bidirectional fine-tuning manuscript lives in [`bidir/`](bidir/).

- [Read the draft](bidir/main.pdf)
- [Build instructions and manuscript files](bidir/README.md)

From the repository root, `make paper`, `make paper-check`, and
`make paper-submission` target this manuscript. Generated tables, figures and
result reports stay with it. The local evidence bundle lives separately in
`artifacts/paper/`.
