# `paper/`

- [`ARGUMENT.md`](ARGUMENT.md) — the spine: what is claimed, in what order, why that order, and
  what would break each section. **Read this first**; it is the part that does not depend on
  results and it is where drafting decisions get made.
- [`main.tex`](main.tex) — skeleton. Prose is written for everything that is argument rather than
  result; every quantity is a `\NUM{}` placeholder.
- [`NUMBERS.md`](NUMBERS.md) — provenance: every figure in the paper traced to the run that
  produced it. Empty until the gate runs, by design.
- `tables/`, `figures/` — generated by `scripts/51_tables.py` and `scripts/52_figs.py`. Not
  hand-edited; re-running the eval regenerates them.

## Unfilled numbers are visible, on purpose

`\NUM{key}` renders as a red `<<key>>` in the PDF, and `\tabinput{name}` renders as a red
`[table not generated yet]`. So a draft circulated with a number still missing shows it, and

```bash
grep -o '\\NUM{[^}]*}' paper/main.tex | sort -u
```

lists everything still outstanding. As results land, `scripts/51_tables.py` writes
`\newcommand` definitions into `paper/numbers.tex`, which `main.tex` inputs when it exists.

**No number is hand-typed.** That rule cost the workshop paper three corrections when it was not
followed, all caught by trying to fill in `NUMBERS.md` and failing.

## Building

There is **no LaTeX toolchain on juno** as of 2026-09-10 — no `pdflatex`, `latexmk`, `xelatex`
or `tectonic` on `PATH`, and the conda `tex` env from the old host did not migrate. Install one
before the first compile:

```bash
conda create -y -p /work/jvl210002/migration/envs/tex -c conda-forge tectonic
/work/jvl210002/migration/envs/tex/bin/tectonic -X compile paper/main.tex
```

Tectonic is one binary, pulls only the packages the document uses, and runs BibTeX and the
reruns itself. Two checks the workshop paper learned the hard way:

```bash
grep -nP '[^\x00-\x7F]' paper/main.tex     # must print nothing: a literal § lands on T1 0xA7
grep -o '\\NUM{[^}]*}' paper/main.tex      # must be empty before submission
```
